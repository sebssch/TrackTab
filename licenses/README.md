# Lizenztexte

Lizenztexte der Drittanbieter-Software, die TrackTab nutzt oder mitliefert. Uebersicht und Quellen: [../THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md). Erzeugt mit `collect_licenses.py`.

- `gnu/` — GPL-2.0, GPL-3.0, LGPL-2.1, LGPL-3.0
- `python/` — Python-Pakete (je Paket ein Ordner)
- `ffmpeg-libs/` — FFmpeg und seine Bibliotheken in `vendor/libs`
- `ui/` — Bestandteile der Oberflaeche (von Hand gepflegt)
